Chamber I · Repository & Knowledge BaseThe Manufacturing Bible

Before a robot can make a statue, someone has to write down how a statue is made: every step, tool, material, judgment call and quality check. We turned a factory's phone videos, photos, STL files and one SOP into a structured knowledge base that software can read and people can check.

In short

Think of it as the factory's recipe book, written so precisely that a machine can follow it, and so honestly that it says “we don't know yet” wherever that's true.

The model

Knowledge = Bible + SKU Profile + Geometry

Most of statue-making is the same for every statue. What differs is small and specific. So we split knowledge three ways, which is how this scales from 2 statues to about 400 without rewriting anything.

Evidence before assumption

Nothing is invented

  • Every fact is tagged Observed, Founder validated or Unknown. Of 42 actions, 24 are verified, 15 partial, 3 still need a factory visit.
  • What we don't know goes into a register instead of a guess: 42 knowledge gaps and 46 process parameters (11 verified, 18 partial, 17 unknown).
  • A founder validation session on 8 July 2026 confirmed answers, which were pushed back into every affected file.
  • JSON is the source of truth. Markdown and CSV copies are generated by scripts so they can never drift.

    Rules we hold ourselves to

    An honest “unknown” beats a confident wrong answer

    Decision entry 4Motion is not an action

    We rejected using “lots of movement” as a stand-in for an action. A plausible wrong label in training data costs more than an empty field.

    Decision entry 14The vision model only describes

    It reports tool, material, motion and before/after. It is never asked to name an action ID.

    Decision entry 16Evidence breaks ties

    An action is picked only when visual evidence separates it from the other candidates by a clear margin.

    Chamber III · Project BThe Training Data Desk

    Project B is where observations become lessons. It takes what Project A saw and turns it into reviewed training labels, each one tied to a Bible ID and approved by a person before any model learns from it.

    In short

    A model is only as good as its labels. Project B checks every label against the Bible, flags anything that doesn't match, and keeps a human in charge of the final yes.
