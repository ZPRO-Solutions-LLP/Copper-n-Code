# Copper & Code — interactive progress preview

A static, dependency-free site (one `index.html` + `assets/`). No build step.

## Deploy
**Netlify:** drag the `site` folder onto https://app.netlify.com/drop — done.
**GitHub Pages:** push the contents of `site/` to a repo (root or `/docs`), then
Settings → Pages → Deploy from branch.

## Local preview
    cd site && python3 -m http.server 8000   # open http://localhost:8000

## Deep links
`#foundation`, `#project-a`, `#project-b` open a chamber directly.
